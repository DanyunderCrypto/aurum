📖 Como obter a API key do Alchemy (1 minuto, grátis)
  1. Vai a alchemy.com e cria conta grátis (Google/email).
  2. No dashboard, clica Create new app (ou "Apps" → "+ Create app").
  3. Dá um nome qualquer (ex: "Aurum") e cria.
  4. Abre a app → botão API Key (canto superior direito).
  5. Copia a API Key e cola aqui em cima.
✓ Uma só key funciona para todas as chains (Ethereum, Base, Arbitrum, Optimism, etc.) — não precisas de uma por chain. Plano grátis chega para uso pessoal.
